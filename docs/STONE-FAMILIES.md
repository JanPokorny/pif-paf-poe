# Stone families

Each row is one effect. Its stones come in up to three strengths:

- **regular**: the weaker form, kept in the pouch, played every duel;
- **one-shot**: a stronger form, gone from the pouch once played;
- **talisman upgrade**: a talisman that makes the regular stone stronger.

Only stones that exist are listed; empty cells are still to be designed. No talisman upgrades a
stone yet.

| Move one stone | Lasso (common): pull an enemy stone beside it | Nudge (common): any stone one step · Relocate (uncommon): one of yours to any empty square | |
| Knock enemy stones off | Bumper (uncommon): push those beside it, off the edge is gone · Frog (common): leap one, it is gone | | |

| Turn a group of squares | Waltz (common): its 2×2 block, clockwise · Bonfire (uncommon): the squares around it, either way | | |
| Slide lines | Shift (common): its row or column, wrapping · 2048 (uncommon): every stone, one way | | |
| Limit where the enemy places | Stinky (common): not beside it · Magnet (uncommon): beside it · Beacon (rare): its row or column | | |

Removed as near duplicates: Whirl (Bonfire in the centre), Undo and Pluck (stones back to the
hand, as Firecracker), Bribe and Turncoat (a stone changing sides, as Swap with an enemy beside it).
Their one-shot slot in "Send a stone back to its hand" is open again.
